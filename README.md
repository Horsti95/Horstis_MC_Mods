# Horstis MC Mods

Eigene Minecraft-Mods (Java, Fabric, MC 26.2) nach der Leitidee **„minimale Assets, maximaler Logik-Impact“** —
alle server-seitig, Mitspieler joinen mit Vanilla-Client.

➡️ **[PLAN.md](PLAN.md) ist die Single Source of Truth**: aktuelle Mod-Liste, Status, Reihenfolge, Roadmap.

Jeder Mod liegt unter [`mods/`](mods/) in einem eigenen, einzeln shippbaren Ordner mit eigener README
(Was macht er? · Steuerung · Installation · Steckbrief).

*Installations-Anleitung und Releases folgen, sobald die ersten Mods gebaut sind.*
